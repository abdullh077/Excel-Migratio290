## The Rule
Mutation hooks are exported as `export const useXxx` (not `export function`), so `grep "^export function use"` misses them. Grep for `export const use` instead.

`UseQueryOptions` in TanStack Query v5 **requires** `queryKey`. When passing inline `query` options with `enabled`, always include the queryKey:
```tsx
useGetUmrahClient(id, { 
  query: { enabled: !!id, queryKey: getGetUmrahClientQueryKey(id) } 
})
```

For simple cases (no `enabled`, just `staleTime`/`retry`), pass nothing and configure at the QueryClient level instead.

**Why:** The Orval codegen uses `UseQueryOptions` directly in the type signature, not `Partial<Omit<...>>`, so TypeScript enforces all required fields.

**How to apply:** Whenever adding `{ query: { ... } }` to a generated hook, check if `queryKey` is in the type — add it if yes.
